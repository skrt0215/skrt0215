## About Me

I'm a Computer Science graduate from the New York Institute of Technology who builds full-stack applications end to end, from gathering requirements to deploying and maintaining production systems. I independently designed and built a production operations platform that was adopted across an organization, and I work with LLM integration, automated data pipelines, and multi-tenant architecture. My background in operations management shapes how I approach technical problems: I care about systems that actually work in the real world.

## What I'm Building

**OVERWATCH** — A production operations command platform that unifies four external systems into a single dashboard. FastAPI backend, PostgreSQL with multi-tenant isolation, React frontend, automated REST API and Selenium data pipelines. Adopted as the foundation of daily operations at the organization that acquired it.

**Meridian** — A multi-tenant SaaS platform for field workforce operations, spanning a FastAPI backend, a Next.js dashboard, and a React Native mobile app. Features an autonomous LLM-powered SMS dispatch pipeline with intent classification and a hardened Claude API integration with retry logic and per-call telemetry.
